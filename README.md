# KebabX 🌯

A modern React website for a kebab business, built with React and Vite.

## Features
- Responsive website layout
- Interactive menu category tabs
- Food-focused hero section
- React component-based architecture

## Tech Stack
- React
- JavaScript
- CSS
- Vite

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
