# Kebabs on Lonsdale 🇦🇺

A modern, responsive website built for **Kebabs on Lonsdale**, a real-world food business in Australia.

The project focuses on creating an engaging online presence, showcasing menu items, and directing customers to external food delivery platforms.

🔗 **Live Website:** [kebabs-on-lonsdale.netlify.app](https://kebabs-on-lonsdale.netlify.app/)

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern UI with custom styling
- Reusable React components
- Dynamic menu rendering using structured data
- Food menu and item details
- Links to external food delivery platforms
- SEO metadata and Google Search Console setup
- Automated deployment through GitHub and Netlify

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/mirza-anas18/kebabs-on-lonsdale.git
```

**2. Navigate to the project directory**

```bash
cd kebabs-on-lonsdale
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

The website is hosted on Netlify and connected to GitHub for continuous deployment.

When changes are pushed to the configured GitHub branch, Netlify can automatically build and publish the updated website.

## 🔍 SEO

Basic SEO setup includes:

- Page title and meta description

- Search engine indexing directives
- XML sitemap
- Google Search Console integration

Search visibility and rankings depend on Google's crawling and indexing processes.
